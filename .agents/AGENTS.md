# Repository Rules

## Git Workflow
- Always push commits ONLY to the `main` branch (`git push origin main`). Do not push to secondary feature branches unless explicitly requested.

## Production Quality & Deployment Standards
- All code written must be production-ready, clean, secure, and deployment-grade.
- Ensure strict input validation, proper HTTP error codes, gracefully handled edge cases, and user-friendly error messages.
- Ensure Prisma queries, database indexes, authentication, and state management adhere to high reliability and security standards.
- Always run end-to-end build and validation checks before confirming completion.
